# HomeBudgetAI 💰

A modern full-stack finance dashboard application built using Angular and ASP.NET Core.

---

# 🚀 Features

✅ Expense Tracking  
✅ Income Tracking  
✅ Monthly Analytics Dashboard  
✅ Pie Chart Analytics  
✅ Edit/Delete Transactions  
✅ Responsive UI  
✅ Modern Dashboard Design  
✅ CRUD Operations  

---

# 🛠 Tech Stack

## Frontend
- Angular
- Tailwind CSS
- Chart.js
- TypeScript

## Backend
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server

---

# 📊 Dashboard Features

- Monthly Expense Analytics
- Expense Category Pie Chart
- Income vs Expense Summary
- Real-time Dashboard Updates
- Transaction Management
